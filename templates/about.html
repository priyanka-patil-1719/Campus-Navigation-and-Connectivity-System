BFS

Breadth First Search

Explore level by level with a first-in, first-out queue.

  1. Mark the start discovered and enqueue it.
  2. Dequeue a vertex and visit it.
  3. Mark and enqueue its undiscovered neighbors.
  4. Repeat until the queue is empty.
Time O(V + E) · Auxiliary space O(V)
DFS

Depth First Search

Explore one branch deeply using recursive calls.

  1. Visit and mark the starting vertex.
  2. Recursively visit an unvisited neighbor.
  3. Backtrack when no unvisited neighbors remain.
  4. Continue until all reachable vertices are visited.
Time O(V + E) · Auxiliary space O(V)
{{ icon('info') }}

BFS finds the fewest-edge levels in an unweighted graph. Neither BFS nor DFS calculates the shortest weighted walking route. This project demonstrates connectivity and traversal.
