Breadth First Search uses a queue. Visit nearby vertices before moving to the next level.

FIFO queue · O(V + E) traversal
DFS

Follow a branch deeper

Depth First Search uses a recursion stack. Follow a branch, then backtrack to the next unvisited neighbor.

Call stack · O(V + E) traversal

Neighbors are explored in insertion order. Traversals visit only reachable vertices and do not use edge weights to choose a path.
